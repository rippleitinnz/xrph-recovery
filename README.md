# XRPH Wallet Recovery

A self-contained offline tool to recover a family seed from XRPH padlock numbers and move funds to a secure wallet.

---

## Background — Why this tool exists

The XRP Healthcare (XRPH) wallet app contained a critical flaw in the way it generated private keys. When a user created a wallet, the app derived the private key from a set of 8 six-digit numbers (the "padlock"). This derivation was deterministic and used insufficient entropy, meaning that **any wallet ever created by the XRPH app can be mathematically reconstructed by anyone who knows the algorithm** — which is now public knowledge following the security disclosure.

This is not a flaw in the XRP Ledger itself. It is specific to the key generation method used by the XRPH wallet application.

**Every account generated by the XRPH padlock function must be treated as permanently compromised.** It does not matter whether your wallet has already been drained or not — the private key to every XRPH-generated wallet is recoverable by anyone with access to the public security report.

---

## Who is affected

**You are affected if:**
- You created a wallet using the XRP Healthcare (XRPH) wallet app
- Your wallet was generated using the padlock (8 groups of 6 digits) method

**You are NOT affected if:**
- Your wallet was created with any other XRPL wallet application (Xaman, Crossmark, Gem, Ledger, etc.)
- You imported an existing seed or keypair into the XRPH app rather than generating a new one through it

This tool is specific to wallets generated by the XRPH padlock function. It will not work for — and is not needed for — any other wallet type.

---

## What you must do

1. Use this tool to recover your family seed from your padlock numbers
2. Import the seed into a secure XRPL wallet app (Xaman, Crossmark, Gem Wallet, or similar)
3. Move **all assets** — XRP, XRPH tokens, XRPHAI tokens, and any other tokens — to a fresh wallet you have created with secure software
4. Delete the compromised account on-chain to close it permanently and recover your XRP reserve

Do not simply move your funds and leave the old account open. As long as the account exists on the ledger with a known compromised key, it remains a risk.

---

## How to use this tool

1. Download `index.html` from the [latest release](../../releases/latest)
2. **Save it to your device** — do not open it directly from a chat app or email
3. Turn off WiFi and mobile data separately. On a computer also unplug any ethernet cable. Do not rely on Airplane Mode alone as WiFi can remain active on some devices
4. Open the saved file in your browser
5. Enter your 8 padlock numbers and recover your seed
6. Re-enable your network and import the seed into your wallet app of choice

---

## Security

- Runs entirely in your browser — no server, no network calls, no external dependencies
- The cryptographic library (@noble/curves + @noble/hashes, MIT licence) is bundled inline
- Input fields are locked when any network connection is detected
- The page wipes all derived values from memory when you use the Shred button

### Verify the file before use

Always verify the SHA-256 hash of the file matches the published value before entering your padlock numbers.

**Mac / Linux**
```bash
shasum -a 256 index.html
```

**Windows (PowerShell)**
```powershell
Get-FileHash index.html -Algorithm SHA256
```

## After recovery

1. Import the family seed (starts with `sEdS…`) into your wallet app using its own import function
2. Verify the address shown matches your XRPH wallet address
3. Move all XRP and tokens to a fresh wallet that was created with secure software — not an exchange account; you must hold the keys yourself
4. Once all assets have arrived safely, delete the compromised account on-chain using your wallet app's account delete function — this closes the account, removes it from the ledger, and returns the XRP reserve to you
5. Delete this HTML file from your device
